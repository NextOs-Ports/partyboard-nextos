# Screenshots

Captures of this port running on the target hardware — an Amlogic device with a
Mali-450 MP (Utgard) GPU, rendering through OpenGL ES 2.0 on the fbdev path.
Taken from the framebuffer at the panel's native 1280×720.

They are here as evidence: each one backs a specific claim made in the main
README.

| File | What it demonstrates |
|---|---|
| `01-title.png` | The port boots and reaches the title screen, rendering correctly |
| `02-party-mode.png` | Party Mode with the 1P/2P/3P/4P indicators — four-controller support |
| `03-board.png` | A full 3D board in play, with the four-player HUD |
| `04-dialog.png` | The dialog and text system, in English |
| `05-minigame.png` | A minigame running, with transparency and the timer HUD |

Images are quantized to a 256-color palette to keep the repository small. At
normal viewing size they are indistinguishable from the raw captures.

> **Note:** these are screenshots of Mario Party 4, which is copyright Nintendo
> and Hudson Soft. They document a port; they are not game data, and no game
> data ships in this repository. If this repository is ever made public, this
> directory is self-contained and can be removed in a single commit.
